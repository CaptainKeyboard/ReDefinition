# ReDefinition.Tests

The unit tests: the mod's decisions that need no game, and the tests that hold the parts of the
repository to what they share.

## Start here

| File | Read it for |
|---|---|
| `tests/ReDefinition.Tests/ReDefinition.Tests.csproj` | The target (.NET Framework 4.8, MSTest) and the KSP assemblies it references |
| `tests/ReDefinition.Tests/ArchitectureTests.cs` | The table of which area of `src` may use which |
| `tests/ReDefinition.Tests/ProxyContractTests.cs` | The render events' ids against the proxy's header |
| `tests/ReDefinition.Tests/RtContractTests.cs` | The raytracing constants and packet layouts against the contract |
| `tests/ReDefinition.Tests/DeveloperDocumentationTests.cs` | The comment check of `tools/DocLock` |
| `tests/ReDefinition.Tests/Fakes.cs` | A fake mod and host for the settings store |
| `tests/ReDefinition.Tests/TestFolders.cs` | `RepoRoot`, which finds the repository, and `TempFolderTests`, the base of tests that write files |

## What it does

Run it from the repository, with KSP 1.12.5 and HarmonyKSP installed:

```
dotnet test tests/ReDefinition.Tests
```

`DeveloperDocumentationTests` builds and runs `tools/DocLock`, which makes it the slowest test. It is in the
category Docs, so `dotnet test tests/ReDefinition.Tests --filter "TestCategory!=Docs"` leaves it out.

- The tests run without the game. KSP's `ConfigNode` and Unity's types come from the game's
  assemblies, which the build copies beside the tests. Types of the test assembly take the place
  of mods (`tests/ReDefinition.Tests/RegistrationTests.cs`).
- The tests cover the settings store, `bundled.cfg`, the settings window's edit model, the
  registrations, the modules, the key bindings and the diagnostics window's options. Each is
  tested as data, with stand-in mods.
- The upscaler, frame generation and the proxy's files are tested without a GPU. They check
  which techniques a card allows and the choices of the rows. They also check NVIDIA's and Intel's
  file lists on archives made here, and Streamline's camera matrices.
- The dashboard's pages and the flight and editor readings are tested as data. The planner's
  route and the stage budget are checked against figures worked out by hand and the stock crafts.
- `tests/ReDefinition.Tests/ForeignAssumptionTests.cs` and
  `tests/ReDefinition.Tests/ScalingHookTests.cs` check the mod's reliance on other code: the
  fingerprints of another mod's methods, and Harmony's targets in KSP's own assembly.

## The tests that hold the parts together

| Test | Holds | Fails when |
|---|---|---|
| `ArchitectureTests` | The usings between areas of `src` against a table | A using is not in the table, or a table entry is no longer needed |
| `ProxyContractTests` | `ProxyEvents` against `src/DxgiProxy/Managed/ProxyContract.h` | An event differs in value, is missing on either side, or shares an id |
| `RtContractTests` | `RtNative` against `src/DxgiProxy/Raytracing/Shaders/RtContract.h` | A constant, a packet offset or a record size differs |
| `FramePacketLayoutTests` | The mod's frame packet against the sizes `FrameGeneration.h` asserts | A size or offset moved |
| `DlssPacketLayoutTests` | The mod's DLSS packet and size query against the sizes `Dlss.h` asserts | A size or offset moved |
| `Fsr3ConstantsLayoutTests` | FSR 3's constants struct against the shaders' | The sizes differ, which shifts the constants without an error |
| `SharedFoundationTests` | The mod's Direct3D 12 packets against the proxy's | A size or offset differs |
| `ShippedRegistrationTests` | The registrations in `GameData/ReDefinition/Mods` | One reads with a problem |
| `RaytracingPlayerStubTests` | The test player's stub against the rig | The stub's sharpness ceiling differs |
| `DeveloperDocumentationTests` | Every element documented, none dirty | `tools/DocLock check` exits 1 |

## Rules of the area

- `tests/ReDefinition.Tests/ArchitectureTests.cs` fails both ways. The table only grows or shrinks
  by a decision made in that file. `src/DxgiProxy` is not part of it.
- The contract tests find the header by walking up from the working folder, so they run inside the
  repository. Change both sides of a contract in one commit.
- `DeveloperDocumentationTests` runs `tools/DocLock` with its `check` command through `dotnet run`.
  It puts the output in the failure message and needs `dotnet` on the path.
- `tests/ReDefinition.Tests/StockCrafts.cs` is generated by `tools/craft_stages.py`. Do not edit
  it.
- [The four channels to native code](../../docs/development/flow-native-channels.md) says which
  of these tests catches which disagreement between the mod and the proxy.
- Building the tests builds the mod, and the mod's build deploys into the game
  ([Building and testing](../../docs/development/building-and-testing.md)). Use
  `-p:DeployToGameData=false` to leave the game alone.
